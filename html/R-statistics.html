R Tutorial - Statistical Analysis

Introduction

These tutorials cover methods both theory and application of statistical techniques in Rstudio. It will generally include a case study, the method, some background information, application in Rstudio, resulting output, and interpretation. There will also be sections for troubleshooting, describing common errors encountered (either with the dataset, output, or code) when using the method. I may also include different packages to compare code output, if relevant. If also relevant, I may include neat things I find along the way for checking assumptions, seeing what models are doing, etc... Although these won't include tutorials on database management, there will be recommendations on database setup.
