R Tutorial - Database Management

Introduction

These tutorials cover database manipulation and management within Rstudio. These generally cover how to modify the data itself, leading to easier statistical analysis. Some examples include adding/removing colums/rows, combining columns, searching for key values, and other basic information. While there may be some mathematical elements involved with these tutorials, its primary function is to help change the dataset as needed, along with learning basic information about that dataset.
