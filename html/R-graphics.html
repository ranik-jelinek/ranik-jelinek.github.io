R Tutorial - Graphics and Visualizations

Introduction

These tutorials cover visualizations and graphics in Rstudio. Examples will be done in both base R and ggplot if possible. Other graphics packages will be used in specific circumstances. These tutorials will not focus on when to use certain graphics, just how to make them. There will be occasional recommendation/necesities for data setup. If you need help with data setup, check out the database tutorials page.
